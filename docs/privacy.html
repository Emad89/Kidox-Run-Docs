Privacy Policy

Kidox Run · Effective 20 September 2026

Kidox Run does not collect any data. It has no analytics, no advertising, no accounts, and no network connection of any kind.

What we collect

Nothing. The app has no code that transmits information anywhere. It does not connect to the internet, so there is no server for information to be sent to and no one for it to be shared with.

The camera

Kidox Run offers an optional way to play in which the player steers by leaning left and right in front of the camera instead of swiping. This is off by default, and the camera permission is only requested if a player chooses it.

When it is in use, camera frames are analysed on the device using Apple's Vision framework to estimate body position. The only result kept is which of three lanes the player is leaning toward. No photo or video is recorded, saved, displayed, or transmitted. Frames are discarded as soon as they are analysed, and none of them ever leave the device.

If camera permission is denied, the game continues normally using swipe controls.

What is stored on the device

Game progress — score, coins, which times tables have been practised, and the chosen settings — is saved in a single file in the app's private storage on the device. It is not readable by other apps, is never uploaded, and is deleted when the app is deleted.

Third parties

There are none. Kidox Run contains no third-party software development kits, no advertising networks, no analytics services, and no social media integrations.

Children

Kidox Run is designed for children aged roughly 6 to 10. It collects no information from anyone, including children. It contains no advertising, no in-app purchases, no chat or messaging, no user-generated content, and no links out to other websites or apps.

Changes

If this policy ever changes, the revised version will be posted on this page with a new effective date.
